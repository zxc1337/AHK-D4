# AHK Mouse Macro - Diablo 4 / D2 / Last Epoch

## Description
- AutoHotkey mouse macro tool for **Diablo IV (D4)**, **Diablo II: Resurrected (D2R)**, and **Last Epoch (LE)**.
- Enables virtual/combined key bindings for mouse left/right/middle buttons and wheel (press, release, double-click, scroll).
- Covers almost all in-game actions and greatly reduces the number of required key presses (by 80%+).
- Compared to the D3 version, added one extra skill slot (total 5 skill slots), which can be bound to any key.

## Recommended Keybinds
- In all games: Keep default bindings, but set one **Force Move** to `Z` and one **Force Stand Still** to `.` (period).
- In **D4**: Disable mouse wheel zoom in options (Options → Controls → Game Features → bottom setting) to free up wheel up/down for custom actions.
- In **D2**: Disable mouse wheel skill switch to free up wheel up/down.

## Supported Resolutions
- Auto features (skill swap in D4, auto game creation in D2) rely on screen ratio. If you don't need them, resolution doesn't matter.
- **D4**: Works best in 16:9. For other ratios use windowed mode scaled to 16:9.
- **D2**: Multi-client auto create/join works with 2550x1440 windowed mode + MDK plugin (or author's WILL plugin pack).

## Usage
- **Toggle macro**: Mouse side button (thumb button).
- Detailed settings → see the in-macro GUI documentation.
